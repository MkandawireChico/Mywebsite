# Chico Mkandawire — Data & Analytics Portfolio

A responsive portfolio website showcasing five focused projects across healthcare analytics, hospital operations, banking, credit risk and medicine inventory.

## View the site
- Open `index.html` locally in a browser, or enable GitHub Pages for this repository.
- GitHub repository: https://github.com/MkandawireChico/Mywebsite

## Structure
- `index.html` — portfolio content and project links
- `styles.css` — responsive visual design

## Publishing with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub will provide the published URL after the Pages deployment completes.

## Project integrity
The portfolio lists exactly five approved projects. Project statuses are intentionally conservative: a live demo link is shown only where a demo URL is documented, and pending release checks are not described as completed deployments or production-ready systems. The showcased datasets are synthetic or simulated and are not real operational records.
